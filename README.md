# Alawaly Real Estate Smart Voice Assistant (المساعد الذكي لشركة العوالي العقارية)

المساعد الذكي الصوتي لشركة **العوالي العقارية** (المتصل عبر LiveKit بموقع الشركة الرسمي [https://www.alawaly.sa/ar](https://www.alawaly.sa/ar)).

يقدم المساعد تجربة صوتية تفاعلية فائقة السرعة للعملاء والزوار:
1. **الترحيب الفوري والتعريف بالشركة**: يبدأ المكالمة مباشرة بالترحيب الرسمي والتعريف بالشركة وتاريخها العريق.
2. **التحكم بشاشة العميل والتنقل بين الصفحات**: توجيه متصفح العميل عبر LiveKit RPC إلى أي صفحة أو مشروع بالتزامن اللحظي مع الصوت.
3. **التحدث بطلاقة وفخر عن الشركة عند زيارة صفحة «عن العوالي»**: استعراض تأسيسها عام 2011، قيادتها برئاسة سليمان بن رميح الرميح، محفظتها التي تفوق 16 مليار ريال و80 مشروعاً و15 ألف منتج في أكثر من 7 مدن، وشراكتها مع الشركة الوطنية للإسكان (NHC) ورؤية 2030.
4. **الإجابة التفصيلية الدقيقة عن المشاريع**: تفاصيل المساحات، النماذج، الغرف، المعالم القريبة، الدعم السكني، ونسب الإنجاز.
5. **أعلى درجات الموثوقية وأقل زمن استجابة (Lowest Latency)**: معمارية معالجة صوتية وتدفق فوري تقلل زمن بدء النطق إلى ما دون 600-900 ميلي ثانية.

```
Caller Mic ──► BVC Noise Cancellation ──► Silero VAD ──► Coda / Cohere ASR
            ──► Turn Detector (v1-mini)
            ──► Streaming LLM (Coda-V2 / Gemini Flash) + LiveKit Tools
            ──► ConcatPhraseTokenizer ──► VoxCPM2 / Coda-V2 TTS ──► Caller Ear
                                       │
                                       └── LiveKit RPC ──► Browser Screen (https://www.alawaly.sa/ar)
```

## 2. منهجية تحقيق أقل زمن استجابة وأعلى موثوقية (Low Latency & High Reliability)

لتحقيق محادثة طبيعية سريعة تشبه التحدث مع إنسان حقيقي، يعتمد النظام على:
1. **التدفق الجزئي الفوري للـ TTS (Phrase-level Streaming)**:
   - بدلاً من انتظار توليد الـ LLM للرد الكامل، يقوم `ConcatPhraseTokenizer` بإرسال أول شبه جملة (4-6 كلمات) فوراً إلى محرك الصوت VoxCPM/Coda، مما يخفض وقت بدء الكلام إلى **~600-800ms**.
2. **الكشف المبكر عن نهاية الكلام (Preemptive Generation & Optimized VAD)**:
   - تفعيل `preemptive_generation=True` لبدء التنبؤ في الـ LLM مع اقتراب صمت المتحدث.
   - ضبط `endpointing_min_delay` عند 0.8s و`vad_min_silence_duration` عند 0.45s للكشف الدقيق عن انتهاء المتحدث دون انقطاع مبكر.
3. **قاعدة المعرفة اللحظية في الذاكرة (Zero-Latency In-Memory Knowledge Base)**:
   - حفظ بيانات المشاريع والمعالم والمواصفات محلياً في الذاكرة (`data/alawaly_catalog.json`) للوصول السريع $O(1)$ دون أي استدعاءات خارجية أو تأخير شبكي.
4. **أدوات موجزة ودقيقة (Crisp Tool Contracts)**:
   - تصميم واجهات الأدوات بحيث تُرجع حقائق مركزة دون إرهاق نافذة السياق الخاصة بالنموذج.

## 3. سلوك المساعد الذكي المطلوب

### أ. بداية المكالمة (Call Initiation):
يطلق المساعد الترحيب المعتمد تلقائياً:
> «مَرْحَبَاً بِكَ فِي العَوَالِي العَقَارِيَّة، أَنَا مُسَاعِدُكَ الذَّكِي. شَرِكَةُ العَوَالِي العَقَارِيَّة رَائِدَةٌ فِي التَّطْوِيرِ العَقَارِيِّ فِي المَمْلَكَةِ مُنْذُ عَامِ 2011، نُقَدِّمُ مَشَارِيعَ سَكَنِيَّةً وَتِجَارِيَّةً نَوْعِيَّةً فِي جُدَّةَ وَالرِّيَاضِ وَعِدَّةِ مُدُن. كَيْفَ أَقْدِرُ أَخْدِمَك اليَوْم؟»

### ب. التنقل بين الصفحات (Navigation):
عند طلب العميل:
- «افتح لي المشاريع» ──► ينتقل المتصفح إلى `/ar/projects`.
- «وريني مشروع آكام هومز» ──► ينتقل المتصفح إلى `/ar/project/akam-homes`.
- «افتح الخريطة التفاعلية» ──► يفتح رابط `https://alawaly-project.vercel.app/`.
- «أبي أتواصل معكم» ──► ينتقل إلى `/ar/contact`.
- «وريني الأخبار» ──► ينتقل إلى `/ar/news/latest`.
- «سجل اهتمامك» ──► يفتح النموذج داخل القائمة الجانبية ويعبّي الحقول عبر `alawaly.fillContact`.

### ج. عند الانتقال إلى «عن العوالي» (/ar/about):
ينتقل المتصفح إلى `/ar/about` ويتحدث المساعد بحرية وطلاقة وفخر عن:
- تاريخ التأسيس عام 2011م بجدة.
- الرئيس التنفيذي سليمان بن رميح الرميح ورؤيته: *«شغفنا في العوالي هو النهوض بجودة حياة الإنسان والارتقاء بمستوى المعيشة من خلال مشاريع عمرانية عملية ومستدامة»*.
- المحفظة الاستثمارية (+80 مشروع، +15 ألف منتج، بقيمة تفوق 16 مليار ريال في أكثر من 7 مدن).
- الشراكة الاستراتيجية مع الشركة الوطنية للإسكان (NHC) ودعم رؤية السعودية 2030.

### د. الإجابة التفصيلية:
- **المشاريع السكنية بجدة**: آكام هومز (شمال جدة)، العوالي هومز التيسير (جاهز 100%، جائزة أفضل سلسلة مشاريع سكنية)، آكام جدة هايتس (152 فيلا مع NHC مساحات خضراء >400 ألف م²)، العوالي هومز المروة (جاهز 100%).
- **المشاريع بالرياض**: العوالي رايز (مكاتب 106 آلاف م² مباع بالكامل)، بولاريس (سكني فاخر مباع بالكامل)، مركز العوالي للأعمال (حي الصحافة، طراز سلماني، مكاتب)، العوالي تاور (45 طابقاً، 7 أبراج مواقف ذكية).
- **قنوات التواصل**: مبيعات `920016488`، استفسارات `8003050004`، واتساب `+966920016488`، إيميل `info@alawaly.sa`، وتطبيق العوالي على App Store وGoogle Play.

## 4. التشغيل والبدء (Running)

### تحميل ملفات VAD وTurn Detector (لمرة واحدة):
```bash
python agent.py download-files
```

### وضع التطوير المحلي (Development):
```bash
python agent.py dev
```

### وضع الإنتاج (Production Worker):
```bash
python agent.py start
```
